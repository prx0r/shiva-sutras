# 05 — ARGUE. Essay A as text, then audit every join cold.

## Compose (`build/SECTION_ARGUMENTS.md`)
All A-clips per section in her order, quotes verbatim from units. No
composed doctrine. Structural notes inline as marked lines (jump /
bridge / note / closure-test) — drafts, never spoken as-is. Questions
open each section (human voice). Record verdicts per section as you go:
FLOWS / TIGHTEST / soft spots with demote-levers / named bridges /
closure tests (does the section's answer land where its question
expects?).

## Audit (`build/JOIN_AUDIT.md` — every adjacent pair, no sampling)
Method: quote-integrity FIRST — re-verify every moved quote against
transcripts (pass-verify protects the source file, not the copies; M18).
Then read each clip→clip join cold and verdict it: OK / SOFT
(audio-decides, self-anchored) / WEAK (needs glue at build — zero
tolerated without a build line). Cross-section joints get the same
treatment (whole-document chain must cohere: IS → obstacle → arrival →
change → mechanism → after). Summary counts (here: 65 joins, 0 WEAK),
the named bridges (build glue, not reorderings), the soft spots for
audio, the closure notes. No reorderings, no cuts proposed at text
level — the arguments are arguments, or the stage fails.
