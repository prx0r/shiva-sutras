# 06 — AUDIT. Prove nesting holds, then sweep B at lock.

## UNFOLDING (`build/UNFOLDING_AUDIT.md` — run 1 vs DRAFT, run 2 vs LOCK)
For each section, judge every grade-A clip against the locked-shape seed:
**E** expands the seed-sentence · **Q** expands the section-question
(legitimate space, seed stays anchor) · **B** bridge/frame (minimal,
allowed) · **W** wobble (pre-flagged, re-test at collate/audio) ·
**N** NEW-IDEA (forbidden — swaps the seed). N must be 0 or the stage
fails. Watch-list (loosest links, Q-clusters, demote-levers) carries to
collate + audio; none are mandatory pre-lock. Re-run at LOCK — cells may
sharpen at ear/key, and verdicts are provisional until then.

## HOLDUP sweep (`build/HOLDUP_SHEET.md`, `build/B_SWEEP.md`,
`build/holdup_verdicts.json` — RUN at lock, provisional before)
The B-membership instrument: every B-row answers ONE question against
the locked seed — does this clip DEEPEN the seed's answer beyond what A
gives? → **KEEP-B** (plays at depth, one-line reason recorded) /
**DEMOTE-C** (texture only) / **LEDGER** (note, never a clip — M21).
Provisional rows (promoted before lock) sweep first. Budgets ≈ A×1.6–2
per section; no superset ever ships (record the lesson, don't repeat the
86-minute mistake). Machine verdicts file is the single source; the sheet
regenerates from unit files (M23). Defects the sweep catches (cell-grade
bugs, nested dups, zero-length windows, label-vs-quote mismatches) get
M-numbers and fixes in the same pass.
Gate after any grade move: `sync_counts.py`, then verify N/0, G0, plain
MATCH. Counts own their number-lines — the tool rewrites them, and its
templates must never regress (a fixed template re-broken is a pipeline
bug, not a typo).
