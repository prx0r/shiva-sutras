# 08 — BEATS. Run-order, bell grammar, speakers, ear-check list.

## Run-order (`custom/BEATS.md` — the build instrument for audio)
`[BELL] 0 → [BELL] A → [BELL] B → [BELL] C`: seed heard 4×, A ⊂ B ⊂ C,
append-only, machinery (question/card/plain/bell) lives INSIDE the
layers as section openers. L0 = essay-0 only; LA/LB/LC = essay-0 +
sections at each depth. Cumulative-play semantics recorded honestly;
delta-replay (each clip once) is noted as the single biggest ear
decision if runtimes run long — never taken silently.

## Beat grammar (per section opener, every layer, every section)
motto-bell → QUESTION (TTS v1, human at ship) → 2-breath pause →
SANSKRIT + TRANSLATION spoken as the card → PLAIN → 1.2 s → unit clips
(each `afade 0.15`, 1.2 s gap) → 2.5 s water → next section. Essay-0
cell: Q → breath → S → T → P → voice. Essay-0 text is the source;
SEED-CAP cells appear only at heads.

## Bells + levels
Motto 880 Hz / 2.5 s opens every section; zoom 220 Hz / 6.0 s crosses
layers only. Standalone cues sit UNDER voice (−20 dBFS-ish), never
masking. Pads v1 = digital silence (1.2 s beat-gap / 2.5 s water and
breaths); at ship = room-tone breaths from lecture gaps. Pause-snap
(±0.3 s to nearest silence) is an audio-QA pass, not optional.

## Speakers (`custom/SPEAKERS.md`) + ear-check (`custom/EAR_CHECK.md`)
Archive voices carry all source language (chant, verses, commentary);
TTS carries questions/plains/cards at v1 (placeholder until human
records + key signs); human owns questions at ship + marked bridges.
Sanskrit-by-TTS is unverified until ear-checked — drop the S-row from
audio before shipping a mispronunciation. EAR_CHECK harvests every
flagged ASR form (contexts + known suspects) with uid + window +
expected word; `naruto`-class caption-critical hits ride the QA list.
Verification itself needs the mp3s — the list is built before audio
lands, checked after.
