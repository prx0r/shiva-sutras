Method: for each of 77 verses, the book's exposition was split into major cutting
points and checked against our Standard audio texts (0 = B1/B1b/B2 transcript windows,
A = core passages, B = his-continuation + Baumer uid quotes + TTS gold). Machine first
pass produced 428 candidate verdicts (`BOOK_GAPS_PROPOSAL.tsv`); every verdict below
is a human read of the book chunk against the covering text. No audio was auditioned
for this document (text comparison only) — cut boundaries and delivery remain ear work.

Legend: COVERED = claim present. SOFT = core present, sub-point thin (acceptable or
minor B-add). GAP[REAL] = missing Level-1/2 point (with transcript location if found =
B-candidate, else ABSENT = no source found). GAP[APPARATUS] = commentary detail
(variant readings, enumerations, parallels, similes) = C material or intentional
thinness. UNVERIFIED = transcript garbled at the relevant timestamps: verify BY EAR
against the book point (transcripts are frozen finding aids; no retranscription —
owner ruling 2026-10-28, see ACTION LIST item 1).
